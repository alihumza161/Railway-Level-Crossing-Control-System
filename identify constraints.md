| Symbol | Meaning |
|---|---|
| TA | `Train_Approaching` (detected by approach sensor) |
| TP | `Train_Present` (train is inside the crossing zone) |
| TC | `Train_Cleared_Confirmed` (exit sensor and tail-end check both confirm clear) |
| BO / BC | `Barrier_Open` / `Barrier_Fully_Closed` |
| WL / AA | `Warning_Lights_On` / `Audible_Alarm_On` |
| RS | `Road_Signal_Red` |
| SF, BF, CL | `Sensor_Failure`, `Barrier_Failure`, `Communication_Loss` |
| SC | `Sensor_Conflict` (sensors disagree) |
| EM | `Emergency_Condition` |
| CCA | `Control_Center_Alerted` |
| TSS | `Train_Stop_Signal_Issued` |
| TTA, T_safe | Estimated time to arrival, and the minimum safe closing time (e.g., 25 s) |
